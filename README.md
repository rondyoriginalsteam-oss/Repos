## Описание
«GitHub User Finder» — это графическое приложение (GUI), написанное на Python с использованием библиотеки `tkinter`. Приложение позволяет осуществлять поиск пользователей на платформе GitHub по их логину, просматривать результаты в виде списка и сохранять понравившиеся профили в локальный список «Избранное». Данные избранных пользователей автоматически сохраняются между запусками программы в формате JSON.

## Как использовать API
В данном проекте используется открытое API GitHub (GitHub Search API). 
Для поиска выполняется GET-запрос по адресу:
`https://api.github.com/search/users?q={query}&per_page=10`

Где `{query}` — это текст, введенный пользователем в поле поиска. Программа использует стандартный модуль `urllib.request` с передачей заголовка `User-Agent` (обязательное требование GitHub API для неавторизованных запросов). Ответ приходит в формате JSON, откуда программа извлекает ключ `login` для каждого найденного пользователя (массив `items`).

## Примеры использования (Тесты)

1. **Позитивный сценарий (Поиск существующего пользователя):**
   * Ввести в поле поиска `torvalds` (создатель Linux).
   * Нажать "Найти".
   * В списке результатов появится пользователь `torvalds` и похожие логины.
   * При выборе логина и нажатии "Добавить в избранное ⭐️", пользователь появится в нижнем списке, а в папке с программой создастся/обновится файл `favorites.json`.

2. **Негативный сценарий (Пустое поле):**
   * Оставить поле поиска пустым.
   * Нажать "Найти".
   * Ожидаемый результат: Программа перехватит ошибку валидации и покажет всплывающее предупреждение "Поле поиска не может быть пустым!".

3. **Граничный сценарий (Пользователь не существует):**
   * Ввести несуществующий набор символов (например, `askjdhasdqwkjehasd`).
   * Нажать "Найти".
   * Ожидаемый результат: API вернет пустой список, в результатах отобразится сообщение "Пользователи не найдены".
